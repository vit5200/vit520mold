# 昇祿鋁業 - 模具雲端管理系統（手機版）

單一 HTML 網頁工具，適合手機使用。

- 模具資料庫搜尋：文字搜尋型號/客戶，並依分類提供專屬尺寸欄位（外徑、內徑、厚度…）與誤差範圍
- 修模版本（-X）、包心長度、量產/試模紀錄管理
- 手動新增、Excel/CSV 批次更新（重複自動覆蓋，修模與生產紀錄保留）、JSON 完整備份/還原
- 單筆或多筆模具分享到 LINE
- 深色/淺色模式與字體大小設定
- 匯出 PDF（自動排除異型材）
- 資料自動儲存於本機瀏覽器（localStorage）

使用方式：開啟 `index.html`，或啟用 GitHub Pages 後以網址開啟，可在手機「加入主畫面」。
